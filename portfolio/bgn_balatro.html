Buck's Game Night: A Balatro Mod

Creator

May 2026

Game Type: Mod

Buck's Game Night is a mod for the game Balatro that I created both for my own enjoyment and as a way to learn and practice coding in Lua. While a good amount of coding for this project was done using tutorials and following in-depth Balatro mod documentation, it was a good exercise for me to practice with standard coding logic. Many of my custom Jokers had to be playtested thouroughly to make sure they didn't break or crash the game in certain scenarios. This was also a good exercise in my art abilities, as almost all of the sprites included in this mod were created by me, either by remixing existing sprites, pixel art-ifying existing designs from other games, or creating a sprite or design entirely from scratch. I plan on continuing to work on this project because I've had a really fun time working on it and have more ideas I'd like to try and code.

This mod requires a PC version of the game "Balatro". Tutorials for how to setup Balatro mods can be found online. Click here to access the GitHub page for my mod!
